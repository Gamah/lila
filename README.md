# lila-mistakes-showcase

Screenshots of every state of the `/mistakes` feature, at 1280x720 and 390x844,
both at 2x. Nothing here is code and nothing here is meant to be merged: this
branch exists only so the images can be referenced from a pull request body,
which is why it is an orphan - it shares no history with `master` and never
appears in a diff.

The images are generated, not curated. Each one is a named state of the feature
captured from a local stack, and the generator that takes them lives outside the
lila working tree on the machine that runs it. Regenerating replaces this
directory wholesale.

Delete the branch once the pull request that uses it is closed.
