Mistakes, state by state

18 named states of the /mistakes feature on branch mistakes, each at desktop 1280×720 and mobile 390×844, both at 2×. Taken 2026-11-04 from a local stack by the generator described here. Every state is built through the feature's own HTTP surface — reset, next, record — so each shot is of the page the server actually serves. Click an image for the full-size PNG.

These are not the players' lichess accounts. The games are imports of the public GCT Sinquefield Cup 2026 broadcast, taken from /api/broadcast/2sMqschv.pgn, claimed to ten local scratch accounts on a development machine and analysed there by a local fishnet at 100k nodes/move — shallower than a lichess manual request. Nothing here reflects anything any of these players did on lichess, and no lichess account was touched. Each shot below links to the broadcast game, and where the page named a position, to that position at the same ply.
